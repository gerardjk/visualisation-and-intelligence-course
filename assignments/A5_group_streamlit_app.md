# A5 — Group Streamlit Data App

## Weight

20%

## Type

Group.

## Description

Groups submit a final deployed Streamlit data app using a public dataset. The app must support defined user stories and communicate a responsible visual interpretation.

## Minimum viable app

```text
1. One public dataset.
2. At least three user stories.
3. One documented cleaning or transformation step.
4. At least two interactive controls.
5. At least three visualisations.
6. Declared FT Visual Vocabulary categories.
7. One clear narrative claim or analytical purpose.
8. One uncertainty, limitation, or caveat section.
9. Data and AI Disclosure inside the app.
10. GitHub repository.
11. Deployed Streamlit link.
12. AI Provenance Matrix.
```

## Rubric

| Criterion | Weight |
|---|---:|
| App runs reliably after deployment | 15% |
| Data loading, caching, and error handling support user trust | 15% |
| Data handling and transformations are sound | 15% |
| Visualisations match declared user stories and Visual Vocabulary tasks | 15% |
| Narrative flow and audience fit | 10% |
| Interactivity adds value | 10% |
| Data and AI Disclosure and provenance are clear | 10% |
| Specialised visualisation decision | 5% |
| Code organisation and repository quality | 5% |
