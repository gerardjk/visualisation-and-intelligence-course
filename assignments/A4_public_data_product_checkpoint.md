# A4 — Public Data Product Checkpoint

## Weight

15%

## Type

Group, mostly automated.

## Purpose

This checkpoint verifies that the Streamlit app has moved from a local prototype to a public data product that another person can open, understand, trust, and use.

## Required submission

1. Deployed Streamlit app URL.
2. GitHub repository link.
3. AI Provenance Matrix draft.
4. Data and AI Disclosure draft.
5. User story map.

## Automated checks

The repository checker looks for:

```text
app entry file
requirements.txt
README.md
valid Python syntax
st.cache_data or equivalent
at least two widgets
at least three chart outputs
empty or error state handling
Data and AI Disclosure terms
Visual Vocabulary terms
user story language
provenance file
user story file
```

## Rubric

| Criterion | Marks |
|---|---:|
| Repository and app URL submitted | 2 |
| App entry file parses as Python | 2 |
| requirements.txt and README present | 2 |
| Cached data loading pattern | 2 |
| Widgets and visual outputs present | 3 |
| Empty/error state handling | 2 |
| Data and AI Disclosure present | 2 |
| Provenance and user stories present | 2 |
| **Total** | **15**, scaled from autograder output |
