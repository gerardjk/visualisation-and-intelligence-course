# A7 — Individual Oral Defence

## Weight

10%

## Type

Individual, live, AI-restricted.

## Duration

4–5 minutes per student.

## Purpose

The oral defence authenticates individual understanding. Students must be able to explain the work they claim to have contributed.

## Question categories

| Category | Example question |
|---|---|
| Contribution | What part of the app did you build? |
| User story | Which user story does this chart support? |
| Visual Vocabulary | Why is this a change-over-time rather than ranking task? |
| Data | What transformation produced this column? |
| Code | What does this function or filter do? |
| Deployment | What would cause this app to fail online? |
| Reliability | Why did you cache this function? |
| Interpretation | Where could the app mislead users? |
| AI use | What did the tool help with and what did it get wrong? |
| Review response | What feedback did your group accept or reject? |

## Rubric

| Criterion | Marks |
|---|---:|
| Explains own contribution | 2 |
| Explains code, data, or deployment choice | 2 |
| Justifies visual-task and chart choices | 2 |
| Identifies limitation, uncertainty, or risk | 2 |
| Explains intelligent-tool use and verification | 1 |
| Communicates clearly under questioning | 1 |
| **Total** | **10** |
