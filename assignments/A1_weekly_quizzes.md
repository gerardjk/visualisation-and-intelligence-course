# A1 — Weekly Quizzes

## Weight

20%

## Format

Seven quizzes across Weeks 1–7. Best six count.

## Purpose

The quizzes provide low-stakes, auto-graded practice in visual vocabulary, chart critique, dashboard reasoning, Streamlit patterns, deployment concepts, specialised visualisation decisions, and responsible interpretation.

## Question types

- Multiple choice.
- Multiple response.
- Classification/matching.
- Assertion-reason.
- Parsons/code-ordering.

## Weekly focus

| Week | Focus |
|---|---|
| 1 | chart claims, intelligent-tool interpretation, governance prompts |
| 2 | FT Visual Vocabulary, encoding, tidy data |
| 3 | dashboard personas, user stories, methodology traps |
| 4 | Streamlit controls, prompt quality, data loading |
| 5 | deployment, caching, empty states, disclosure |
| 6 | maps, flow, animation, 3D, JavaScript literacy |
| 7 | uncertainty, causality, accessibility, quality review |

## Grading

Auto-graded in the LMS. The lowest quiz mark is dropped.
