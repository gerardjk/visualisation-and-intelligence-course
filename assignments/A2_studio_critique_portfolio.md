# A2 — Studio Critique Portfolio

## Weight

15%

## Type

Individual, supervised, AI-restricted.

## Description

Students complete three short critiques in supervised studio time in Weeks 1, 2, and 7. Each critique is approximately 500–600 words and uses the standard critique template.

## Required critique fields

```text
1. What is the main claim?
2. Who is the likely audience?
3. What visual task is being performed?
4. Which FT Visual Vocabulary category best describes the task?
5. What visual encodings are used?
6. What works well?
7. What is misleading, missing, uncertain, inaccessible, or overclaimed?
8. What would you change?
9. Which course concept supports your critique?
```

## Rubric

| Criterion | Marks |
|---|---:|
| Main claim and audience identified | 3 |
| Visual task and Visual Vocabulary category identified | 3 |
| Encoding critique is specific | 3 |
| Missing context, uncertainty, limitation, or accessibility issue identified | 3 |
| Redesign suggestion is concrete | 2 |
| Course concept used correctly | 3 |
| Clarity and professional tone | 1 |
| **Total** | **18**, scaled to 15% |
