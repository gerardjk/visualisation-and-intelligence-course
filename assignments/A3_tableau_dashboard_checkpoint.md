# A3 — Tableau Dashboard Checkpoint

## Weight

10%

## Type

Individual.

## Purpose

This checkpoint ensures every student has used Tableau Public to design a dashboard for a persona and user story. Tableau is required, but it is not the centre of the course.

## Required submission

1. Tableau Public link.
2. Dashboard screenshot.
3. Structured submission form.

## Minimum requirements

```text
1. One-page dashboard.
2. At least three visual elements.
3. At least one filter or interactive control.
4. Clear title and subtitle.
5. Source note.
6. One annotation.
7. One caveat or limitation.
8. Persona and user story.
9. Primary FT Visual Vocabulary category.
10. Methodology or data-quality issue considered.
```

## Rubric

| Criterion | Marks |
|---|---:|
| Tableau link and screenshot submitted | 2 |
| Three visual elements present | 2 |
| Filter/control included | 1 |
| Title, source, annotation, caveat included | 2 |
| Persona and user story included | 1 |
| Visual Vocabulary category justified | 1 |
| Methodology or data-quality issue identified | 1 |
| **Total** | **10** |
