# Public Data Product Checkpoint Autograder

This checker performs static scaffold checks for the group Streamlit project.

It does **not** grade design quality, ethical adequacy, or interpretive validity. It checks that routine project components exist.

Run:

```bash
python autograder/check_public_data_product.py starter_app
```

JSON output:

```bash
python autograder/check_public_data_product.py starter_app --json
```
