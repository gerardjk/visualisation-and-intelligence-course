# Class 1 — Seeing Data: Visualisation, Intelligence, and Interpretation

## Core question

How do charts create meaning?

## Learning outcomes

By the end of this session students should be able to:

1. Explain how selection, encoding and framing turn data into meaning.
2. Distinguish a fluent interpretation from a justified insight.
3. Use an AI assistant to produce a chart and verify every claim it makes about the data.
4. Critique a human-made chart and an AI-generated interpretation using course terminology.
5. Record significant intelligent-tool use with the course disclosure block.

## Content topics

- visualisation as selection and interpretation
- human and machine intelligence in visualisation
- generated charts and hallucinated insight
- the five-step verification ladder for generated output
- data governance from the start (Indigenous Data Sovereignty)

## Notebook

`seeing_data_activities.ipynb` — five exercises, AI assistant expected:

1. Summary statistics vs the picture (Anscombe).
2. Assistant-generated chart of the transport dataset + TRACE/CHECK/TEST assertions.
3. Claim audit of a generated interpretation: supported / unsupported / unverifiable.
4. Make a true chart lie twice (truncated axis, cherry-picked window), then the honest version — the verification cell inspects the axes.
5. Stretch: rolling mean with an uncertainty band.

## Studio activity
