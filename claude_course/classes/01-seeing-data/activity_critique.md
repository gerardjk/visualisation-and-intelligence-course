# Studio Activity — Critique 1

Compare one human-made chart with one AI-generated chart or generated chart
interpretation. Work in pairs; 45 minutes.

**Phases:** Read (10 min) → Interrogate (15 min) → Verify (10 min) → Share (10 min).

Answer for each artefact:

```text
Main claim:
Audience:
Visual task:
What is compared:
What is omitted:
What works:
What misleads or overclaims:
What would need to be verified:
Redesign suggestion:
```

Then answer the responsibility checkpoint:

```text
Who is represented?
Who benefits from this visualisation?
Who could be harmed or misled?
What limitation must be disclosed?
What did intelligent tools help with, and how was the output checked?
```
