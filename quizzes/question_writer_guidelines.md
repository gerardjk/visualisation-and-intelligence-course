# Quiz Item-Writing Guidelines

1. Test one idea per item.
2. Put the central problem in the stem.
3. Use three strong options rather than four weak options.
4. Build distractors from common misconceptions.
5. Avoid “all of the above.”
6. Avoid trick wording.
7. Make visual-task classification explicit.
8. For code items, prefer Parsons/order problems early and short debugging later.
9. For interpretation items, distinguish observation, inference, and causal claim.
10. For accessibility items, include a concrete chart scenario.
