# Quiz Materials

The sample item bank is stored as CSV for portability. It can be converted into LMS-specific formats such as Canvas QTI or Moodle XML by local tooling.

Recommended item types:

- MCQ and multiple response.
- Classification/matching.
- Assertion-reason.
- Parsons/code ordering.
- Short numeric interpretation with tolerance.

Avoid free-response grading for weekly quizzes unless staff workload allows it.
