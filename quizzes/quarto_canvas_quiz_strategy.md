# Quarto + Canvas quiz strategy

Quarto does not replace Canvas quizzes. Use Canvas New Quizzes or the institutional LMS for anything grade-bearing.

Use Quarto for:

- practice items,
- worked examples,
- quiz study guides,
- links to Canvas quizzes,
- item-writing documentation,
- question-bank source files.

Use Canvas for:

- timed quizzes,
- automatic marks,
- accommodations,
- gradebook sync,
- official submission records.

Recommended workflow:

1. Write the question bank in `quizzes/item_bank_sample.csv`.
2. Use it to create Canvas New Quiz questions.
3. Link the Canvas quiz from the weekly Quarto page.
4. Keep the Quarto page focused on learning, not grading.
