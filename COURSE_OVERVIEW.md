# Course Overview

## Course title

**Visualisation and Intelligence**

## Subtitle

**Narrative, Critique, and Analytics**

## Description

This 8-week course teaches students to design, critique, build, deploy, and defend visual data products in an environment where intelligent tools can generate plausible charts, captions, code, and interpretations.

Students use **Tableau Public** for accessible dashboard construction and **Streamlit** for deployable interactive data apps. They also learn enough web design and JavaScript literacy to understand how modern web-native visualisations are built and when specialised tools such as D3, Vega-Lite, Plotly.js, Leaflet, deck.gl, or Three.js might be appropriate.

The course is not vendor training. Tableau and Streamlit are tools; the intellectual centre is judgement.

## Core premise

In an AI-rich environment, production is no longer the only bottleneck. Students must learn to judge whether a visualisation is accurate, ethical, accessible, persuasive, technically reliable, and fit for purpose.

## Recurring design scaffold

Students repeatedly ask:

1. Who is the user?
2. What is the user story?
3. What visual task is being performed?
4. Which FT Visual Vocabulary category fits that task?
5. What chart or interface supports the task?
6. What could mislead?
7. What data and intelligent-tool use must be disclosed?
8. Can the student defend the design under questioning?

## FT Visual Vocabulary categories

The course uses the FT Visual Vocabulary as a practical chart-selection scaffold:

| Category | Core question |
|---|---|
| Deviation | How does a value differ from a baseline or target? |
| Correlation | How are two variables related? |
| Ranking | What is higher, lower, first, last, best, or worst? |
| Distribution | How are values spread? |
| Change over time | How does something evolve? |
| Magnitude | How large are values compared with each other? |
| Part-to-whole | How does a whole divide into parts? |
| Spatial | Where are values located or concentrated? |
| Flow | How does something move, transfer, or connect? |

## Learning outcomes

By the end of the course, students should be able to:

1. Explain how visualisations create meaning and shape interpretation.
2. Use the FT Visual Vocabulary to classify visual tasks.
3. Choose visual encodings appropriate to data type, audience, and purpose.
4. Use personas and user stories to design dashboards and data apps.
5. Build a one-page Tableau Public dashboard.
6. Build and deploy a Streamlit data app.
7. Load, transform, cache, validate, and disclose data in a public app.
8. Explain when specialised visualisations such as maps, flows, networks, animation, and 3D are justified.
9. Apply basic web-design principles to interactive visualisation.
10. Explain the role of HTML, CSS, JavaScript, SVG, Canvas, and WebGL in web visualisation.
11. Communicate uncertainty, limitations, missingness, accessibility concerns, and causal caveats.
12. Use intelligent tools responsibly and maintain an AI Provenance Matrix.
13. Defend data, design, code, deployment, and intelligent-tool decisions orally.

## Position on intelligent tools

Students may use intelligent tools for brainstorming, coding, debugging, rewriting, chart suggestions, critique, and documentation. They remain responsible for every submitted claim, line of code, chart, data transformation, and interpretation. Students must document significant tool use in the AI Provenance Matrix.

The course does not rely on AI-detection software. It relies on task design, provenance, peer review, and oral defence.
