# Intelligent Tool Use Policy

## Plain-language rule

You may use approved intelligent tools, but you are responsible for everything you submit.

## Permitted uses

You may use tools for:

- brainstorming visual approaches,
- chart-task classification,
- writing draft code,
- debugging errors,
- summarising documentation,
- drafting captions,
- checking grammar,
- generating alternative interpretations,
- critiquing your own work.

## Required disclosure

Document significant use in the AI Provenance Matrix.

Minimum columns:

```text
Date, Tool/model, Purpose, Prompt summary, Output summary, Accepted/modified/rejected, Verification step, What the tool missed or got wrong, Responsible student
```

## Not acceptable

- Submitting code you cannot explain.
- Submitting invented sources or unsupported claims.
- Hiding significant tool use in AI-integrated tasks.
- Using private or restricted data in public tools.
- Treating generated interpretation as verified analysis.

## Verification examples

| Tool output | Verification step |
|---|---|
| generated code | run it, inspect it, explain it, test edge cases |
| chart suggestion | map it to a Visual Vocabulary category and task |
| data interpretation | check against actual data and source metadata |
| disclosure draft | check against actual provenance and dataset documentation |
| alt text | verify chart type, axes, pattern, values, and caveat |
