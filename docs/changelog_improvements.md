# Changelog and Improvement Notes

## Current package revision

This revision incorporates the latest course-design decisions:

- Week 1 renamed to **Seeing Data: Visualisation, Intelligence, and Interpretation**.
- FT Visual Vocabulary integrated across all major tasks.
- User stories added as a core design scaffold from Week 3 onward.
- Week 5 reframed from a technical deployment week to **From Prototype to Public Data Product**.
- “Nutrition Label” replaced with **Data and AI Disclosure** in student-facing materials.
- Web design and JavaScript literacy added to Week 6.
- “Red Team” naming removed and replaced with **Visualisation Quality Review**.
- Starter app enhanced with user stories, disclosure, cached loading, empty states, ranking, distribution, change-over-time, and spatial overview.
- Public Data Product Checkpoint autograder strengthened.
