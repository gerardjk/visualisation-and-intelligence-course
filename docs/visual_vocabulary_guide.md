# FT Visual Vocabulary Guide

The FT Visual Vocabulary is a practical chart-selection aid. It helps students choose visual forms by purpose rather than by aesthetics.

## Course categories

| Category | Use when the task is to... | Common forms |
|---|---|---|
| Deviation | show difference from baseline, target, or norm | diverging bar, dot plot, variance chart |
| Correlation | show relationship between variables | scatterplot, bubble plot |
| Ranking | order items | sorted bar, lollipop, dot plot |
| Distribution | show spread or shape | histogram, box plot, violin, beeswarm |
| Change over time | show temporal pattern | line, area, small multiples, slope graph |
| Magnitude | compare sizes | bar, column, proportional symbol |
| Part-to-whole | show composition | stacked bar, treemap, mosaic |
| Spatial | show location or geographic pattern | choropleth, proportional symbol map, hex map |
| Flow | show movement, transfer, or connection | Sankey, alluvial, flow map, network |

## How students should use it

Every major visualisation should include:

```text
Visualisation purpose:
FT Visual Vocabulary category:
Chosen chart type:
Why this chart fits the task:
What could mislead:
Simpler alternative considered:
```

## Common mistakes

- Choosing a map when geography is only incidental.
- Choosing a pie chart for precise comparison.
- Choosing animation when static small multiples would compare better.
- Choosing 3D for non-spatial categorical data.
- Choosing a Sankey when a grouped bar chart would be clearer.

## Oral defence prompt

```text
You classified this visualisation as [category]. Why? What would change if the task were ranking rather than change over time?
```
