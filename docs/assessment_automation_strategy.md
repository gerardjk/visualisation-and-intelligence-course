# Assessment Automation Strategy

## Automate structure, not judgement

This course automates completion, structure, basic functionality, and scaffold checks. Human marking remains necessary for interpretive judgement, ethical reasoning, and oral authentication.

## Automation map

| Assessment | Automation target |
|---|---|
| Weekly quizzes | fully auto-graded |
| Tableau checkpoint | structured form + link/screenshot check |
| Public Data Product Checkpoint | static repository autograder |
| Group app | automated scaffold checks + human rubric |
| Visualisation Quality Review | structured report + human judgement |
| Oral defence | human only, with standardised rubric |

## Repository autograder checks

- entry app file exists,
- Python parses,
- `requirements.txt` exists,
- README exists,
- cached loading pattern exists,
- at least two widgets,
- at least three charts,
- empty or error state,
- Data and AI Disclosure language,
- Visual Vocabulary language,
- user story language,
- provenance file,
- user story file.

## Recommended marking approach

For large cohorts:

- auto-grade all routine scaffold checks,
- manually inspect all failed checkpoints,
- sample 10–20% of passed checkpoints,
- focus staff time on quality review and oral defence.
