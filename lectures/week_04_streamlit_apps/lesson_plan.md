# Week 4 — Interactive Data Apps with Streamlit

## Core question

How does a user interact with the data?

## Learning outcomes

By the end of this session students should be able to:

1. Explain the week’s core concept in relation to their own project.
2. Apply the relevant tool or design scaffold.
3. Critique or revise an artefact using course terminology.
4. Record any significant intelligent-tool use where relevant.

## 3-hour structure

| Time | Segment | Purpose |
|---|---|---|
| 0:00–0:15 | Opening example | Ground the week in a concrete visual artefact |
| 0:15–1:00 | Concept | Introduce key ideas and vocabulary |
| 1:00–2:00 | Build / analyse | Apply the concept using tools or templates |
| 2:00–2:45 | Critique / repair | Review artefacts and identify improvements |
| 2:45–3:00 | Exit ticket | Capture next action and unresolved issue |

## Content topics

- Streamlit app structure
- data loading patterns
- filters and charts
- interface basics
- AI-assisted coding with provenance

## Studio activity

Build a local minimum viable Streamlit app.

## Exit ticket

```text
One design decision I made today:
One risk or limitation I noticed:
One thing I need to verify before next week:
```
