# Visual Vocabulary Example

## User story

As a policy adviser, I want to compare which transport modes remain below their 2019 baseline, so that I can prioritise follow-up analysis.

## Task classification

| Field | Response |
|---|---|
| Primary task | Compare change over time against a baseline |
| FT category | Change over time + deviation |
| Chosen chart | Indexed line chart |
| Alternative | Yearly grouped bar chart |
| Why rejected | Hides monthly variation and recovery shape |
| Risk | Methodology changes can create artificial jumps |
