# Web Visualisation Stack Comparison

| Tool | Best for | Not ideal for |
|---|---|---|
| Tableau Public | quick dashboards for public sharing | private data, custom frontend behaviour |
| Streamlit | Python data apps and prototypes | highly customised frontends |
| Altair/Vega-Lite | declarative chart grammar | very bespoke interactions |
| D3.js | custom web visualisation | quick no-code dashboards |
| Leaflet/folium | web maps | dense analytical dashboards |
| deck.gl/pydeck | large geospatial WebGL | simple categorical charts |
| Three.js | 3D scenes | ordinary business charts |
