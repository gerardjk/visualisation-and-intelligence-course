# Manifest

## Root files

- `README.md`: package overview and quick start.
- `COURSE_OVERVIEW.md`: course rationale, outcomes, and assessment structure.
- `COURSE_OUTLINE.md`: detailed weekly outline.
- `SCHEDULE.md`: week-by-week schedule.
- `INSTRUCTOR_GUIDE.md`: operational guidance for coordinators and tutors.
- `STUDENT_QUICKSTART.md`: setup and workflow guide for students.

## Folders

- `assignments/`: assessment briefs and rubrics.
- `autograder/`: public data product checkpoint checker.
- `datasets/`: synthetic dataset generator and dataset guidance.
- `docs/`: guides for AI policy, visual vocabulary, user stories, disclosure, web design, and automation.
- `examples/`: JavaScript literacy and visual vocabulary examples.
- `lectures/`: weekly lesson plans, slide outlines, and activities.
- `quizzes/`: sample auto-graded quiz item bank and item-writing guidance.
- `starter_app/`: working Streamlit starter app.
- `templates/`: reusable student submission templates.
