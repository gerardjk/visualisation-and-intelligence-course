# Starter App — Public Transport Recovery Explorer

This app is a teaching scaffold for the group Streamlit project. It demonstrates:

- cached data loading,
- relative file paths,
- user stories,
- FT Visual Vocabulary categories,
- filters and charts,
- empty/error state handling,
- Data and AI Disclosure,
- AI Provenance Matrix placement.

The dataset is synthetic. Replace it with an approved public dataset for assessment.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Public Data Product Checklist

- Can another person open it?
- Can another person understand what it is for?
- Can another person see where the data came from?
- Can another person see what the data excludes?
- Can another person use the controls without breaking it?
- Can another person verify how intelligent tools were used?
