# Choosing Visual Forms

## Core question

What visual task are we performing?

## Core message

Chart selection begins with the comparison or judgement a user needs to make, not with a chart name or visual effect.

## Learning outcomes

Students should be able to:

- translate a question into a visual task;
- use the FT Visual Vocabulary to classify that task;
- explain why position and length usually support more precise comparison than area or colour;
- reshape data into a tidy form and verify the transformation;
- compare several valid charts and justify a selection for a stated audience.

## Preparation

Students need `pandas`, `matplotlib` and `numpy`. The notebook creates its own deliberately messy transport dataset so it does not depend on network access.

Instructor materials:

- the Choosing Visual Forms slides;
- the notebook opened and run once;
- printed or digital Chart Choice Decision Record;
- selected Atlas examples for magnitude, distribution, correlation, time and colour.

## Three-hour plan

| Time | Activity | Teaching purpose |
|---|---|---|
| 0:00–0:15 | Same data, different question | Show that chart choice depends on task |
| 0:15–0:40 | Visual Vocabulary sort | Establish task categories |
| 0:40–1:00 | Encoding precision | Compare position, length, area and colour |
| 1:00–1:15 | Tidy-data demonstration | Connect data structure to available charts |
| 1:15–1:25 | Break | — |
| 1:25–2:25 | Choosing Visual Forms notebook | Clean, verify, chart and compare |
| 2:25–2:45 | Chart Choice Decision Record | Require an explicit selection and rejection |
| 2:45–2:55 | Gallery walk | Test whether charts answer their stated question |
| 2:55–3:00 | Exit ticket | Record the task, selection and rejected alternative |

## Facilitation notes

- Keep returning to the question the audience must answer.
- Accept that several charts may be defensible; assess the reasoning rather than a single canonical answer.
- Ask students to name the visual channel, not just the chart type.
- Require a check after every Copilot-proposed data transformation.
- If Copilot suggests a pie chart or dual axis, use it as a comparison opportunity rather than banning it without analysis.

## Evidence of learning

Collect:

- verified tidy dataset;
- three candidate charts;
- completed Chart Choice Decision Record;
- one rejected alternative with a specific reason;
- exit ticket.
