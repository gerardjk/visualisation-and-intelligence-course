# Critique and Repair

Work individually for ten minutes, compare with a partner for ten minutes, then revise your response.

## Read the artefact

| Prompt | Response |
|---|---|
| What is the main claim? | |
| Who is the likely audience? | |
| What decision or judgement does it support? | |
| What is directly visible? | |
| What is interpretation rather than observation? | |

## Test the design

| Prompt | Response |
|---|---|
| What variables are encoded? | |
| Which visual channels are used? | |
| What comparison is easy? | |
| What has been aggregated, omitted or hidden? | |
| What could mislead or be overclaimed? | |

## Verify and repair

| Prompt | Response |
|---|---|
| What data or source would you check? | |
| What alternative view would you create? | |
| What would you change in the chart? | |
| Write a repaired caption | |

## Responsibility checkpoint

Who benefits from this interpretation? Who could carry the cost if it is wrong?
