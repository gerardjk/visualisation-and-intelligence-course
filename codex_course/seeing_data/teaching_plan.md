# Seeing Data

## Core question

How do charts create meaning?

## Core message

A chart is a claim about how the world is organised. The claim is produced through selection, encoding, comparison, framing and omission.

## Learning outcomes

Students should be able to:

- distinguish data, encoding, observation, insight and narrative;
- explain why identical summary statistics can conceal different structures;
- separate a visible pattern from an unsupported causal claim;
- identify what an AI-generated interpretation needs verified;
- use representation and governance questions in a chart critique.

## Preparation

Students need a Python notebook environment with `pandas`, `matplotlib` and `numpy`. GitHub Copilot is optional: every task remains possible without it.

Instructor materials:

- the Seeing Data slides;
- the notebook opened and run once before class;
- the Critique and Repair activity sheet;
- selected Atlas images for Anscombe, Snow, AIATSIS and Bertin.

## Three-hour plan

| Time | Activity | Teaching purpose |
|---|---|---|
| 0:00–0:10 | Silent chart reading | Students write what they see before hearing an explanation |
| 0:10–0:30 | Anscombe prediction and reveal | Establish that summaries are selective |
| 0:30–0:45 | Evidence, encoding, claim and narrative | Establish shared vocabulary |
| 0:45–1:05 | Snow worked example | Separate spatial pattern, inference and causal evidence |
| 1:05–1:15 | AI interpretation comparison | Show that fluency does not guarantee validity |
| 1:15–1:25 | Break | — |
| 1:25–2:20 | Seeing Data notebook | Calculate, plot, prompt, test and repair |
| 2:20–2:45 | Critique and Repair activity | Apply the framework to an unfamiliar example |
| 2:45–2:55 | Pair exchange | Test whether claims are supported and specific |
| 2:55–3:00 | Exit ticket | Record a claim, a risk and a verification need |

## Facilitation notes

- Do not show Anscombe’s plots before students predict their appearance.
- Ask students to use “the chart shows” only for visible evidence. Reserve “this suggests” for interpretation.
- Avoid presenting Snow’s map as proof by itself. Ask what additional evidence supports causation.
- Treat the AIATSIS material as a governance discussion, not merely another map example.
- During Copilot use, require students to retain their initial prediction and prompt summary.

## Evidence of learning

Collect:

- completed notebook checks;
- one repaired caption;
- the Critique and Repair sheet;
- exit ticket: “One claim, one limitation, one thing to verify.”
