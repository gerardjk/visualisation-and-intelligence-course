# Data dictionary: POOL-01

| Field | Meaning |
|---|---|
| `year` | Calendar year. |
| `anomaly_c` | Annual global mean surface temperature anomaly, °C relative to the 1951–1980 baseline. |
| `lowess_c` | Lowess-smoothed (5-year) anomaly, °C. |
| `uncertainty_95_c` | Published 95% uncertainty half-width, °C; available through 2018. |
| `uncertainty_low_c` | Annual anomaly minus the published 95% uncertainty half-width, °C. |
| `uncertainty_high_c` | Annual anomaly plus the published 95% uncertainty half-width, °C. |

The supplied CSV is a documented extract of the linked source data; no values were digitised from chart pixels.
