# Vision, Color and Perception

This lesson begins with physical light, follows its compression by the visual
system, develops colour matching and CIE chromaticity, and ends with a small
Streamlit explanatory app.

## Student materials

- `beamer/vision-color-perception.pdf`: lecture slide deck;
- `notebooks/vision_color_perception_lab.ipynb`: guided Jupyter lab;
- `notebooks/vision_colour_app.py`: complete Streamlit spectrum explorer;
- `notebooks/hello_colour.py`: minimal first Streamlit app;
- `notebooks/data/`: official CIE 1931 2° colour-matching data and metadata.

## Rebuild

```bash
python scripts/build_materials.py
cd beamer
tectonic vision-color-perception.tex
```

Run the app from the notebook folder:

```bash
python -m streamlit run vision_colour_app.py
```

The CIE data are reproduced under CC BY-SA 4.0. The cone curves and spectral
examples generated by the build script are explicitly schematic.
